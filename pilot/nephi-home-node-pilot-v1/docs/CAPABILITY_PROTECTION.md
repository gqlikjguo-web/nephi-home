## REAL budget
Default is zero calls. Deterministic green, a model-facing impact, reviewed exact candidate digest, explicit affected case IDs and finite call/token caps are all required. A completed case cannot be replayed; interrupted attempts need an explicit reason and remain charged. Each turn is capped at two Understanding calls.
The trusted impact manifest identifies model-facing authorities. The trusted case map selects unchanged approved cases and their formal prior-turn dependencies. Missing coverage fails with `REAL_CAPABILITY_UNCOVERED`; no new question, answer or fabricated coverage is introduced. This candidate does not claim the old thirteen-case oracle covers all twenty-eight capabilities. A required atomic installation still cannot waive REAL. Existing trusted REAL requirements remain additive. If a legacy rule requires REAL while the new model-impact evidence does not establish eligibility, qualification blocks for independent review; it neither silently drops the legacy requirement nor spends an unrelated REAL budget.
The Gate seals the exact selected set, product digest, owner-reviewed task budget, per-call output cap and plan digest. The harness validates this binding before opening the isolated Gate DB, and meters every actual transport request. Calls are fsynced before dispatch; provider-reported input/output/total tokens are fsynced on response. A conservative byte/output reservation limits spend before each dispatch, but is not reported as actual tokens. Missing usage or uncertain transport usage remains unknown and blocks further calls. Headers, request bodies, raw provider output and secrets are excluded from the usage ledger. Every case completes at most once; existing evidence files and workflow rerun attempts are rejected. A newly approved run still requires an explicit reason bound into the task and ledger; the mechanism does not assert a global external billing history that it cannot observe.
The legacy no-plan harness route remains only for the old trusted Gate during installation; once this governance is trusted, any required REAL must pass the new plan and budget checks. Neither route is invoked by this task. The runner's validation clock is shared across State/C01/provider; request timeout timing remains real wall clock. No 22-case default is introduced.
Preflight eligibility is not permission to make calls. Budget/ledger functions are external governance. No REAL was authorized/executed by this task.
