# JunZan AI 專案永久知識管理

## 唯一可信來源

Repository 是 JunZan AI 專案唯一可信的知識來源。

任何會影響產品方向、架構、安全、營運或後續決策的重要知識，都必須寫入 Repository 並接受版本控制。未進入 Repository 的內容，不視為永久專案知識。

## 對話與記憶的界線

- ChatGPT Memory 只保存跨情境仍成立的高層原則，不保存專案執行狀態或細節。
- ChatGPT 對話與 Codex Session 是暫時的協作介面，不是專案紀錄。
- 不得依賴聊天紀錄還原需求、決策、架構、風險或完成狀態。
- 對話中形成的重要知識，必須在工作結束前寫入適當的 Repository 文件。

## 永久知識的歸屬

- 核心產品原則：`JUNZAN_AI_CONSTITUTION.md`
- 重大長期決策：`DECISIONS.md`
- 重要產品演進：`CHANGELOG_INTERNAL.md`
- 永久安全規則：`SECURITY.md`
- 待處理工作：`NEXT_TASKS.md`
- 可重複避免的事件與教訓：`LESSONS_LEARNED.md`

同一項知識只應由一份主要文件負責，其他文件以連結引用，避免多份副本逐漸不一致。

## 維護原則

- 文件必須與造成變化的程式或決策在同一個變更中更新。
- 只記錄可長期使用的知識，不保存聊天摘要或短期工作過程。
- 內容失效時必須明確修訂或移除，不得讓過期資訊繼續被當成事實。
- 所有結論必須能追溯至程式碼、測試、資料模型、正式決策或可驗證證據。
