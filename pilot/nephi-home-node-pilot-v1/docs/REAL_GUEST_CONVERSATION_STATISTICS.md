## 方法與限制

- 對話單位：一個 CSV 檔；有效對話需至少包含一則 `User` 訊息。
- 角色：`User` 為客人，`Account` 為業者；傳送者姓名欄完全不進入輸出。
- 分類：離線規則式多標籤語料統計，用於了解覆蓋需求；不等同 JunZan AI runtime 的 Planner 或 CanonicalRequest。
- 回覆配對：連續 User 訊息形成一個客人 turn，緊接的 Account turn 視為業者回覆。
- 個資：不輸出檔名或 CSV 標題中的帳號名稱；電話、Email、帳號、證號與明確姓名欄位以占位符取代。
- 時間：CSV 含逐則日期與時間，但報告不輸出時間戳，也不分析回覆延遲。
- 「通常不用回覆」是歷史語料用途分類，不是強制產品政策；有實質房型、日期、人數等短訊息仍需結合上下文處理。
