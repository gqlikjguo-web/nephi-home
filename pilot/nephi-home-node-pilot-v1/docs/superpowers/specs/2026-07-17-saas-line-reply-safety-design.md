# SaaS LINE 回覆安全修正設計

## 目標

修正房型公開名稱、未知設備 FAQ 錯配與月份價格文案，且所有判斷只依各 property 已確認資料，不寫死任何業者。

## 設計

- 房型：由公開 `name`、`type` 與短 `description` 組合；去除重複、排除管理／內部文字，限制單段與總長。bundle 不拼接系統產生的描述，且不輸出 ID。
- 設備：一般「有哪些設備」可回覆已確認設備資料；特定設備必須在已確認設備 FAQ／safe fact 中有明確文字證據，否則沿用真人轉接與 review queue。
- 價格：由房型／bundle 的四類結構化價格產生回覆，欄名固定為「週一至週四、週五、週六及連續假期、週日」；不使用含月份的自由文字價格規則。既有日期覆寫資料與管理流程不變。

## 驗證

先新增失敗測試，涵蓋無房號名稱、房型／包棟篩選、公開文字限制、設備已知與未知、四類價格、月份排除、review queue、去重、備註隔離及多 property 隔離，再執行完整回歸。
