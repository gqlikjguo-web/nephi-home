# JunZan AI Agent 工作入口

任何 Agent 或 Codex 任務開始前，必須先閱讀 [規則權威索引](docs/RULES_INDEX.md)，再依索引載入本次工作適用的唯一權威文件。不得用 ChatGPT 對話、Memory、Session 或未寫入 Repository 的交接內容取代 repository 證據。

本專案繼承 repository 根層 `AGENTS.md` 的全部誠信、證據及完成聲明底線。專案規則可以更嚴格，但不得弱化根層底線；若兩者衝突，停止工作並回報，不得自行採用較寬鬆版本。

維護文件時遵守 `docs/RULES_INDEX.md` 的唯一責任分工：同一知識只保留一份權威敘述，其餘文件使用相對連結。核心能力、安全邊界或當前狀態改變時，只更新索引指定的責任文件，不覆寫歷史決策或把未證明結果標成完成。
